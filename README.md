# Swapit

Swapit es una aplicación que conecta a estudiantes para que puedan intercambiar objetos y servicios de manera efectiva y eficiente.

## Descripción

La aplicación de intercambio de objetos y servicios permite a los estudiantes crear una cuenta, buscar objetos y servicios disponibles para intercambio, contactar a otros estudiantes interesados, acordar los términos y condiciones de la transacción y realizar la transacción. La aplicación proporciona herramientas para facilitar la transacción y garantizar la seguridad de los usuarios.


## Funcionalidades

- Crear una cuenta
- Buscar objetos y servicios disponibles para intercambio mediante el uso de palabras clave y categorías
- Filtrar los resultados de la búsqueda por ubicación
- Enviar mensajes directamente a otros estudiantes interesados en intercambiar objetos y servicios
- Discutir los detalles de la transacción, como los objetos o servicios que se ofrecen para el intercambio y los términos y condiciones de la transacción.
- Llegar a un acuerdo de intercambio
- Facilitar la transacción
- Calificar y evaluar a los usuarios


## Requisitos

- Node.js
- Expo


## Instalación

- Clonar el repositorio
- Instalar las dependencias mediante npm install dentro de la carpeta frontend y backend
- Configurar la conexión a la base de datos en el frontend en el archivo .env (reemplazar por ip local)
- Ejecutar el servidor de cliente mediante
  ### $ npm start 
- Ejectutar el servidor de base de datos mediante
  ### $ npm run dev
